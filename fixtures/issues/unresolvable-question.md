---
title: Should Slugify support non-ASCII letters?
labels: scope:engineering
---

Some titles contain accented or non-Latin letters. Should `Slugify` keep them,
transliterate them (`é` to `e`), or drop them?

This is a product question and needs a decision from a person; it is not a
code change. An agent given this issue should make **no edits** and say why.
